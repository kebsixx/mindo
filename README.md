# Mindo

Dari suara dosen jadi paham, sekali klik.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run dev server:
```bash
npm run dev
```

3. Open `http://localhost:3000`

- `design.md` - UI/UX spec

- Next.js 16 (static export)

- Tailwind CSS 4
