## Temuan per keparahan

### P0 — memblokir tugas inti

**1. Pipeline AI tidak pernah dijalankan** *(Implementation Integrity, R-26/C-2)*
Lokasi: `src/app/processing/page.tsx`
Empat tahap (Transkrip, Ringkasan, Mindmap, Flashcard) dirender dari state statis `pending` dan tidak ada satu pun kode yang memanggil agen di `src/lib/ai/agents/` (`transcribe.ts`, `summarize.ts`, `mindmap.ts`, `flashcard.ts`, `tutor.ts` tidak diimpor halaman mana pun). Tidak ada `useEffect` yang memproses `materialId`. Akibatnya `allDone` tidak akan pernah `true`, tombol "Lihat Hasil" tidak pernah muncul, dan hasil tidak pernah tersimpan. **Alur produk utama tidak bisa selesai.**

**2. Toaster tidak pernah dirender** *(Accessibility/States, R-27)*
Lokasi: `src/app/layout.tsx` (tidak ada `<Toaster />`); `src/components/ui/toaster.tsx` ada tapi tak dipakai.
Semua halaman memanggil `toast()` untuk error penting: file >25 MB, gagal simpan materi, mikrofon ditolak, gagal uji koneksi. Semuanya hilang tanpa jejak, jadi state error aplikasi ini secara efektif tidak ada.

**3. Empat tautan ke rute mati `/dashboard`** *(R-24, Hard Gate)*
Rute yang benar-benar ada (dari `next build`): `/`, `/material`, `/processing`, `/recording`, `/settings`.
- `src/app/material/page.tsx` — tombol kembali
- `src/app/processing/page.tsx` — tombol kembali **dan** tombol "Batal" (`handleCancel`)
- `src/app/recording/page.tsx` — tombol kembali
- `src/app/settings/page.tsx` — tombol "Lanjut ke Dashboard" (`goToDashboard`)

### P1 — melanggar WCAG AA / merusak kepercayaan

**4. Anchor navigasi mati di beranda** *(R-24)*
`src/app/page.tsx` — nav `#cara-kerja` dan `#privasi` tidak punya target (grep: 0 `id="cara-kerja"`/`id="privasi"`). "Lihat semua" di kepala Riwayat juga menunjuk `#riwayat`, yaitu section itu sendiri → tidak melakukan apa pun (R-26).

**5. Tombol menu mobile tidak berfungsi** *(R-26, C-4)*
`src/app/page.tsx` — `<Button aria-label="Buka menu">` tanpa `onClick`. Nav desktop `hidden ... md:flex`, jadi di layar <768 px pengguna tidak punya navigasi sama sekali.

**6. Teks dan ikon berwarna lime gagal kontras** *(R-25, Hard Gate; juga melanggar design.md §2 "Lime hanya untuk latar, bukan warna teks")*
- `src/app/material/page.tsx:124` — chip istilah kunci `bg-primary/10 text-primary`
- `src/app/settings/page.tsx:111` — badge "Direkomendasikan" `text-primary`

`#53F16F` di atas putih ≈ **1,5:1** (syarat: 4,5:1 teks normal, 3:1 ikon). Jauh di bawah ambang.

**7. Tab "Tanya Mindo" adalah placeholder yang tidak berfungsi** *(R-26; juga melanggar design.md §8.5 "Bukan tab keempat" dan §8.4 switcher tiga segmen)*
`src/app/material/page.tsx` — isinya cuma "Fitur tutor AI akan segera hadir." `src/components/chat-panel.tsx` sudah ada tapi tidak pernah dipakai.

**8. Warna hardcoded di luar sistem token** *(Theming, R-29; design.md §2/§8.3 tidak memuat warna ini)*
- `src/app/processing/page.tsx` — `bg-blue-50 border-blue-200 text-blue-600`, `bg-green-50 ... text-green-600`, `bg-red-50 ... text-red-600`

**13.
